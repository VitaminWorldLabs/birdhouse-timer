# Birdhouse Timer v1.1.0

## Release scope
- Preserves four independent estimated birdhouse timers and the 190px compact overlay.
- Uses the fixed overlay title **Birdhouse Timers** and **Birdhouse Timers [DM]** in public Demo Mode.
- READY status text is bright green (`#00FF00`); birdhouse location labels remain white.
- Preserves configurable Off / 5 / 10 / 15 minute advance warnings.
- Adds independent READY preferences for red in-game chat and desktop notifications (both default On).
- Shows an actionable Time Tracking disabled overlay warning and one red chat warning per inactive period.
- Respects RuneLite's global focused-notification preference for desktop delivery.
- Consolidates READY events discovered within the existing fixed 10-second coalescing window.
- Preserves account-specific birdhouse records and per-cycle notification deduplication.

No Guided Run, Preparation Assistant, tier advisor, inventory checklist, or Farming expansion is included.
